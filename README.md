# 영화관으로 간 AI 리터러시 · 웹부록 (AInsight@Movie)

「영화관으로 간 AI 리터러시: 대화하는 AI에서 몸을 가진 AI, 생명을 읽는 AI까지, 영화로 배우는 AI 원리와 실습」(이연우 지음)의 웹부록입니다.

- `notebooks/`: 장별 코랩 실습 15개입니다. 책의 QR 코드를 찍으면 바로 코랩에서 열립니다.
- `chNN/t1 … t4/`: 책의 예고편 QR이 가리키는 짧은 주소입니다.
- `chNN/sim/`: 장별 체험 시뮬레이터입니다. 코딩 없이 브라우저에서 바로 됩니다. 목록은 `sim/`에 있습니다.
- `chNN/lab/`: 책의 웹부록 QR이 가리키는 짧은 주소입니다.
